링크로 사진 넣기

사진을 길게 누르거나 오른쪽 클릭해서 "이미지 주소 복사"한 링크를 붙여 넣어 주세요. 여러 장은 줄을 바꿔서 넣으면 돼요. 구글 드라이브·드롭박스 공유 링크도 돼요(전체 공개일 때). 사진이 파일 안에 들어가지 않아서 임시저장과 HTML 파일이 훨씬 가벼워져요.

HTML 파일로 저장

HTML 파일로 저장할 때는 이미지를 링크로 넣어야 파일 크기가 커지지 않아요. HTML 코드를 받아서 쓰려면 꼭 링크로 이미지를 넣어 주세요!

링크로 넣은 사진이 엑박(깨진 그림)으로 보이는 이유
  • 사진 주소가 아니라 웹페이지 주소인 경우 — 게시글·핀 주소 말고, 사진을 길게 누르거나 오른쪽 클릭해서 "이미지 주소 복사"한 링크를 넣어 주세요.
  • 사진을 다른 곳에서 못 쓰게 막아 둔 사이트 — 네이버 블로그·카페, 인스타그램, 일부 커뮤니티 사진은 그 사이트 밖에서 열면 엑박이 떠요.
  • 시간이 지나면 사라지는 주소 — 인스타그램·페이스북·디스코드 등의 사진 주소는 며칠 뒤 만료돼서 처음엔 보이다가 나중에 엑박이 될 수 있어요.
  • 비공개이거나 지워진 사진 — 구글 드라이브는 "링크가 있는 모든 사용자"로 공유해야 해요. 원본 사진을 지우면 엑박이 돼요.

확인 방법: 링크를 새 창에 붙여 넣었을 때 사진만 단독으로 뜨면 괜찮아요. 오래 쓸 사진은 imgur, postimages 같은 이미지 호스팅 사이트에 올린 뒤 그 이미지 주소를 쓰는 게 가장 안전해요.
